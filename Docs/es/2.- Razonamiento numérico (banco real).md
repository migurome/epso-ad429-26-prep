# 3. Tests reales de razonamiento numérico (ORSEU)

Este capítulo es una transcripción fiel del libro de práctica completo *"Numerical Reasoning MCQ for European institution competitions"* de Emmanuel Hetru y Jean-Luc Bizeur (ORSEU, 2012, ISBN 978-2-918796-08-4): doce tests completos de diez preguntas cada uno (120 preguntas en total), cada uno reproduciendo la tabla o gráfico original, el texto exacto de la pregunta y las cinco opciones con letra (a–e) tal como aparecen impresas, incluyendo "imposible saberlo" como una quinta opción habitual. Este es el material de práctica principal para esta materia: trata su formato de cinco opciones, su estilo de preguntas y sus explicaciones resueltas como la calibración auténtica para el examen real. En el capítulo siguiente encontrarás un banco complementario de 40 preguntas generadas por IA (formato de cuatro opciones, redactado antes de localizar este libro real) para repeticiones adicionales.

La sección `## ANSWERS` que figura más abajo reproduce la explicación completa resuelta del propio libro para cada pregunta, incluida la aritmética concreta empleada para llegar a la cifra correcta; este método paso a paso es el principal valor del libro original, por lo que se transcribe con detalle en lugar de resumirse. Los nombres de países ficticios (Poldavia, Levonia, Telonia, Zogland, Muravia, Venalia, Buldonia, Galonia, Albana, Boronitz, Crovaka, Denitz, Estunil) se mantienen exactamente como los usa la fuente; cualquier parecido con países o datos reales es pura coincidencia, tal como señala la propia fuente. Un pequeño número de gráficos de la fuente no tiene etiquetas de datos impresas; en esos casos, la tabla ofrece valores aproximados leídos en las líneas de cuadrícula del gráfico, claramente marcados como "(aprox.)"; no obstante, cada cálculo de la sección de Respuestas reproduce las cifras exactas que utiliza el propio libro.
