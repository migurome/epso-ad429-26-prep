### Notación

Dado que este es un documento de texto, las figuras se representan mediante los siguientes símbolos. Lee esta leyenda una vez antes de empezar: la necesitarás durante todo el banco.

**Formas (pares rellena / vacía):**

| Forma | Rellena | Vacía |
|---|---|---|
| Círculo | ● | ○ |
| Triángulo (genérico / apuntando hacia arriba) | ▲ | △ |
| Cuadrado | ■ | □ |

**Recuento:** se repite el símbolo — `●●` significa dos círculos, `●●●` significa tres círculos, y así sucesivamente. Salvo que una pregunta indique lo contrario, el orden en que se escriben los símbolos repetidos no tiene ningún significado.

**Rotación / dirección:** se utilizan dos familias de símbolos:

- *Flechas de brújula*, para elementos de dirección pura del puntero: → ↗ ↑ ↖ ← ↙ ↓ ↘ (recorriendo la brújula en incrementos de 45°).
- *Triángulos direccionales*, cuando una forma en rotación también necesita mostrar el relleno: ▲ ▶ ▼ ◀ (rellenos, apuntando hacia arriba / derecha / abajo / izquierda) y △ ▷ ▽ ◁ (vacíos, las mismas cuatro direcciones).

Cuando la rotación se describe con palabras en lugar de con símbolos, se indica entre paréntesis, p. ej. "△ (rotated 90° clockwise)".

**Tamaño:** el tamaño por defecto (sin marcar) es medium. Cuando el tamaño varía, se indica entre paréntesis en una escala de cuatro puntos: **(small) < medium, sin marcar < (large) < (extra-large)**.

**Posición dentro del marco:** cuando importa la ubicación de un único elemento dentro de su panel, su posición se indica entre paréntesis mediante una cuadrícula 3×3 de etiquetas: *top-left, top-centre, top-right, mid-left, centre, mid-right, bottom-left, bottom-centre, bottom-right*.

**Las matrices** se muestran como tablas Markdown 3×3 en las que la novena celda (inferior derecha) se sustituye por «?». **Las secuencias** se muestran como una línea de 4-5 paneles seguida de «?». **Los elementos de figura intrusa** muestran cinco figuras con letras, A-E; cuatro comparten una regla oculta y una la rompe — debes identificar cuál.

> *Elementos de secuencia y matriz: elige la opción, A-D, que continúa correctamente la secuencia o completa la celda que falta. Elementos de figura intrusa: cuatro de las cinco figuras con letras, A-E, comparten una regla; elige la figura que la rompe.*

Antes de responder, formula con tus propias palabras la regla (o reglas) que rige el elemento, y comprueba cada atributo — forma, recuento, relleno, rotación, tamaño, posición — de uno en uno, en lugar de juzgar la figura completa de golpe.
